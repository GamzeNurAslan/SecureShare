# 11. Hafta Görev ve Test Planı

## Hafta Amacı

Bu hafta proje teslimi öncesinde tüm modüllerin son kez test edilmesi, raporun tamamlanması ve proje sunumunun hazırlanması hedeflenmektedir.

## Büşra’nın Görevleri

- [ ] Backend, web uygulaması ve API endpoint’lerini son kez kontrol etmek.
- [ ] Açık kalan hata veya eksikleri düzeltmek.
- [ ] Kod tekrarlarını ve kullanılmayan dosyaları temizlemek.
- [ ] README dosyasındaki endpoint, kurulum ve teknoloji bilgilerini son hâline getirmek.

## Hava’nın Görevleri

- [ ] Şifreleme, MinIO, audit log ve erişim kontrolü testlerini son kez çalıştırmak.
- [ ] Tüm backend testlerinin başarılı olduğunu doğrulamak.
- [ ] Güvenlik açısından parola, JWT, KEK, DEK ve `.env` bilgilerinin repoda bulunmadığını kontrol etmek.
- [ ] Final test sonuçlarını kısa bir teknik değerlendirme notuna dönüştürmek.

## Gamze’nin Görevleri

- [ ] Web ve mobil uygulamanın uçtan uca kullanıcı senaryosunu test etmek.
- [ ] Final raporunu düzenlemek.
- [ ] Mimari, görev dağılımı, test sonuçları ve ekran görüntülerini rapora eklemek.
- [ ] Sunum slaytlarını hazırlamak.
- [ ] Demo sırasında izlenecek kayıt → giriş → yükleme → paylaşma → indirme senaryosunu hazırlamak.

## Genel Kabul Kriterleri

- [ ] Kullanıcı kayıt olabilir ve giriş yapabilir.
- [ ] JWT ile korunan işlemler çalışır.
- [ ] Dosya şifreli olarak MinIO’ya kaydedilir.
- [ ] Dosya metadata bilgileri PostgreSQL’de bulunur.
- [ ] Yetkili kullanıcı dosyayı indirebilir.
- [ ] Yetki kaldırıldığında erişim engellenir.
- [ ] Kritik işlemler audit log’a yazılır.
- [ ] Otomatik testler başarılıdır.
- [ ] Rapor, README ve sunum günceldir.

## Hafta Sonu Çıktıları

- [ ] Teslime hazır SecureShare uygulaması.
- [ ] Final teknik raporu.
- [ ] Sunum dosyası.
- [ ] Demo senaryosu.
- [ ] Son test sonuçları ve ekran görüntüleri.
