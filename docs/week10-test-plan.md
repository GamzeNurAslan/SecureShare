# 10. Hafta Görev ve Test Planı

## Hafta Amacı

Bu hafta web ve mobil arayüzlerin son kullanıcı için iyileştirilmesi, kurulum dokümantasyonunun tamamlanması ve sistemin teslim öncesi çalıştırılabilir hâle getirilmesi hedeflenmektedir.

## Büşra’nın Görevleri

- [ ] Web uygulamasında responsive tasarımı kontrol etmek.
- [ ] Dosya listesi, paylaşım, indirme ve silme ekranlarını düzenlemek.
- [ ] Boş liste, yükleniyor, başarılı ve hata durumlarını web arayüzünde göstermek.
- [ ] README dosyasındaki backend ve web kurulum adımlarını güncellemek.
- [ ] Ortam değişkenleri için `.env.example` dosyasını kontrol etmek.

## Hava’nın Görevleri

- [ ] Docker Compose ile PostgreSQL ve MinIO kurulumunun temiz bir ortamda çalıştığını doğrulamak.
- [ ] Veritabanı ve MinIO için yedekleme/geri yükleme prosedürünü dokümante etmek.
- [ ] Uygulamanın yeniden başlatılması sonrası veri erişimini test etmek.
- [ ] Kurulum ve çalıştırma adımlarını başka bir bilgisayarda uygulanabilirlik açısından kontrol etmek.

## Gamze’nin Görevleri

- [ ] Mobil arayüzün farklı ekran boyutlarında görünümünü kontrol etmek.
- [ ] Mobil ekranlardaki Türkçe metinleri, hata mesajlarını ve yönlendirmeleri düzenlemek.
- [ ] Giriş, kayıt, dosya listesi, yükleme ve indirme akışlarını kullanıcı gözüyle test etmek.
- [ ] Uygulamanın ekran görüntülerini rapor ve sunum için düzenlemek.
- [ ] Kullanım senaryosunu adım adım açıklayan kısa bir kullanıcı rehberi hazırlamak.

## 10. Hafta — Son Arayüz Düzenlemeleri

### Web ve Mobil

- [ ] Tüm ekranlarda SecureShare renk, yazı tipi ve bileşen düzenini ortaklaştırma
- [ ] Gereksiz veya çalışmayan butonları kaldırma
- [ ] Ekran görüntülerini rapor ve sunum için hazırlama
- [ ] Kullanıcı senaryosunu baştan sona arayüz üzerinden test etme

## Genel Kabul Kriterleri

- [ ] Web uygulaması masaüstü ve mobil tarayıcıda kullanılabilir görünür.
- [ ] Mobil uygulama farklı ekran boyutlarında bozulmadan çalışır.
- [ ] Yeni bir geliştirici README adımlarını izleyerek projeyi çalıştırabilir.
- [ ] `.env` dosyasında gizli değerler bulunur ve Git’e gönderilmez.
- [ ] Docker Compose ile gerekli servisler başlatılabilir.

## Hafta Sonu Çıktıları

- [ ] Düzenlenmiş web ve mobil arayüzler.
- [ ] Güncel README ve kurulum dokümantasyonu.
- [ ] Yedekleme/geri yükleme notları.
- [ ] Kullanıcı rehberi ve uygulama ekran görüntüleri.
